# Project Context

## Project Name

Sharad Tiwari – AI Engineer & AI Consultant Portfolio

---

# Project Vision

This project is NOT a traditional software engineer portfolio.

The goal is to build a premium website that positions Sharad Tiwari as an experienced AI Consultant and Machine Learning Engineer capable of delivering production-grade AI solutions for businesses.

The website should feel like the homepage of a boutique AI consulting company rather than an individual developer portfolio.

Visitors should immediately understand:

- I solve business problems using AI.
- I have real enterprise experience.
- I build production-ready systems.
- I am available for consulting and freelance projects.
